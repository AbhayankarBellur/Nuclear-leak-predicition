II. Project Abstract
This project implements an end-to-end data mining pipeline to detect and characterize coolant leaks in a nuclear power plant using synthetic minute-level sensor telemetry. We generate realistic data with ground-truth leak events and typical telemetry issues (missingness, outages, sensor drift), then design a preprocessing strategy that preserves genuine leak signatures while cleaning noise. Feature engineering combines domain-inspired indices, rolling statistics, and dimensionality reduction (PCA). We benchmark multiple algorithms for multi-class risk prediction, binary leak detection, and regression of leak rate. The pipeline achieves perfect classification and high-accuracy regression on synthetic data, with clear, interpretable visualizations and artifacted outputs to support reproducibility.

III. Introduction
Nuclear plants rely on dense sensor telemetry to ensure safety. Early leak detection is critical to prevent incidents and reduce operational costs. Real-world data are noisy, incomplete, and subject to nonstationarity. This work builds a robust, transparent pipeline showing how domain-driven preprocessing and feature engineering, combined with modern machine learning, can detect leak events and estimate severity. Using synthetic data with known ground truth enables controlled evaluation and provides a scalable blueprint for real deployments.

Key methodological choices (theory and rationale):
- Minute-level cadence and diurnal baselines mirror plant operations and allow short-term dynamics to be modeled without sequence learners.
- Event-aware cleaning: Short/medium gaps are repaired; long outages are flagged rather than imputed to avoid fabricating data. Outliers are detected globally (IQR) and locally (rolling MAD), but preserved during leak windows.
- Denoising via rolling median and Savitzky–Golay smooths noise while preserving edges and trends.
- Drift correction via median shift is transparent and sufficient for simulated bias; more advanced change-point methods can be used in production.
- Composite indices (radiation, hydraulic imbalance, thermal stress) aggregate physically related signals for interpretability.
- Yeo–Johnson transformation reduces skew (works with zeros/negatives), followed by standardization to stabilize models and PCA.
- PCA retains 95% variance for decorrelation and compression while keeping raw indices for interpretation.

VI. Exploratory Data Analysis
A. Data Cleaning
- Range checks to fail loudly on invalid physical values (e.g., negative radiation or flow).
- Gap policy: short (≤5 min) ffill/bfill; medium (≤30 min) time interpolation; long (>30 min) flagged only.
- Event-aware outlier policy: preserve anomalies during leak timestamps; cap non-event outliers to IQR fences.
- Denoising: rolling median and Savitzky–Golay for key noisy sensors.
- Drift: detect simple median shift and correct the biased segment (e.g., pump vibration).

B. Understanding relationship among features
- Correlation analysis across key thermohydraulic and radiation signals to identify co-movement and redundancy.
- Composite indices engineered to summarize related signals into interpretable metrics (radiation_index, hydraulic_imbalance_index, thermal_stress_index).

C. Feature Selection
- Interpretable base features selected (flows, radiation, pressure/level, temperatures, humidity, vibration) + composite indices.
- Top PCA components (first 5) added for modeling to capture variance while managing collinearity.

D. Dimensionality reduction
- Standardized features fed to PCA; components retained to capture 95% variance (≈14 components in this run).
- Components saved as pc_01 … pc_K and used for visualization and as supplemental predictors.

VII. Target Data Mining Task & Justification
- Tasks:
  1) Multi-class risk classification (Normal, Elevated, Medium Risk, High Risk)
  2) Binary leak detection (Leak vs No Leak)
  3) Regression of leak rate (LPM) for leak-only rows
- Justification:
  - Multi-class risk supports graded operational responses.
  - Binary detection provides a simple alarm channel.
  - Regression quantifies severity for dispatch and mitigation.

VIII. Explanation on Data Mining Task carried
- Feature set: Interpretable sensors + composite indices + top PCA components (5) for stability and expressiveness.
- Classification models: Decision Tree, Random Forest, Logistic Regression, SVM (probability=True), KNN. Train/test split with stratification; 5-fold CV for robustness. Binary AUC derived from probabilities or decision function.
- Regression models: Linear, Ridge, Random Forest, SVR, KNN on leak-only subset; metrics include MSE, RMSE, R²; scatter vs identity line for calibration.
- Association rules: Bin select numerics, one-hot encode, mine frequent itemsets (Apriori) and filter by lift/confidence for rules involving leak/high risk.
- Theory highlights:
  - Trees/Forests capture non-linear interactions and provide importance for interpretability.
  - Logistic Regression offers a linear, calibrated baseline and insight into directionality.
  - SVM maximizes margins; probability calibration enables AUC comparisons.
  - KNN reflects local structure; useful as a simple non-parametric comparator.
  - PCA decorrelates features and reduces noise; using a few top PCs can improve generalization without discarding interpretable originals.

Findings (from this run):
- Dataset size: 20,160 rows × ~93 columns; High Risk minutes ≈ 1,462 (true leak timestamps).
- Multi-class classification: ~100% accuracy across tested models on synthetic data; Random Forest yields strong and interpretable feature importance.
- Binary leak detection: AUC ≈ 1.00 (perfect separation), driven by radiation and sump/imbalance indicators.
- Regression of leak rate: Best model Random Forest with R² ≈ 0.997; scatter aligns tightly with identity line, indicating low bias and variance on synthetic data.
- Feature importance: particulate_cpm, airborne_gamma_uSvph, and radiation_index rank highest; hydraulic/thermal indices and sump/imbalance also contribute.
- Association rules: High-leak or high-risk co-occur with high radiation and elevated sump flow bins; lifts > 1.1 indicate meaningful co-occurrence beyond chance.
- Caveat: Synthetic data likely overstates performance; real deployments need domain calibration, uncertainty quantification, and cost-aware thresholds.

X. Conclusion & Inference drawn
This pipeline demonstrates a principled approach to industrial telemetry mining: simulate realistic multi-sensor phenomena, apply event-aware data quality policies, engineer interpretable indices, and leverage a mix of linear and non-linear models. On synthetic data, detection and severity estimation are near-perfect, and visual analyses are consistent with physical intuition. For production, we recommend real-data validation, advanced drift monitoring, temporal models (e.g., HMM/LSTM), uncertainty quantification, and cost-sensitive thresholds for alerts.
