SECTION 1 — Synthetic Data Generation
Goal: Create realistic minute-level sensor data with injected leak events, false positives, missingness, outages, and drift.

Key techniques:
- Minute cadence over 14 days with diurnal patterns
- Multiple correlated process sensors and derived signals
- Leak events (gradual/rapid) injected with multi-sensor signatures
- False-positive spikes (radiation/humidity)
- MCAR missingness, contiguous outages, and sensor drift

SECTION 2 — Preprocessing & Data Quality
Goal: Repair short/medium gaps, flag long outages, detect/cap non-event outliers, denoise, and correct drift while preserving true events.

Key techniques:
- Range checks and missingness profiling
- Gap categorization: short (ffill/bfill), medium (time interpolation), long (flag only)
- Outlier detection: IQR + rolling-MAD; policy to preserve event-period anomalies
- Denoising: rolling median and Savitzky–Golay
- Drift detection: median-shift heuristic with correction

Code snippet (gap handling and flags):
```python
# Short gaps: forward/backward fill with limits
for col in sensors:
    df_shortfilled[col] = df[col].ffill(limit=5).bfill(limit=5)

# Medium gaps: time-based interpolation
for col in sensors:
    df_interp[col] = df_shortfilled[col].interpolate(method="time", limit=30)

# Long gaps: flag, do not impute blindly
def contiguous_nan_segments(series):
    is_na = series.isna().astype(int)
    groups = (is_na != is_na.shift()).cumsum()
    for _, sub in series.groupby(groups):
        if sub.isna().all():
            yield sub.index[0], sub.index[-1], len(sub)

flags = pd.DataFrame(index=df.index)
for col in sensors:
    mask = pd.Series(False, index=df.index)
    for s, e, L in contiguous_nan_segments(df[col]):
        if L >= 31:
            mask.loc[s:e] = True
    flags[col + "_outage"] = mask
```

Code snippet (outlier policy and denoising):
```python
# IQR thresholds
q1, q3 = s.quantile(0.25), s.quantile(0.75)
iqr = q3 - q1
lower, upper = q1 - 1.5*iqr, q3 + 1.5*iqr

# Preserve event anomalies; cap only non-event outliers
event_mask = df_interp["ground_truth_leak_flag"].fillna(False)
non_event = ~event_mask
cap_mask = non_event & ((df_interp[col] < lower) | (df_interp[col] > upper))
df_cleaned[col] = df_interp[col]
df_cleaned.loc[cap_mask, col] = df_cleaned.loc[cap_mask, col].clip(lower, upper)

# Denoising
df_cleaned[col + "_rolling_median"] = df_cleaned[col].rolling(5, center=True, min_periods=1).median()
df_cleaned[col + "_savgol"] = savgol_filter(
    df_cleaned[col].ffill().bfill().values, window_length=11, polyorder=2, mode='interp'
)
```

Code snippet (drift correction):
```python
def detect_and_correct_drift(series):
    mid = len(series)//2
    first_med, second_med = series.iloc[:mid].median(), series.iloc[mid:].median()
    shift = second_med - first_med
    if abs(shift) > 3 * series.std():
        corrected = series.copy()
        corrected.iloc[mid:] = corrected.iloc[mid:] - shift
        return corrected, shift
    return series, 0.0

pv_corr, pv_shift = detect_and_correct_drift(df_cleaned["pump_vibration_mm_s"].ffill().bfill())
```

SECTION 3 — Feature Engineering & Transformations
Goal: Create interpretable indices, rolling statistics, slopes, power transforms, scaling, and PCA components for downstream modeling.

Key techniques:
- Rolling mean/std windows: 5, 15, 60 minutes
- Slopes/deltas for key thermohydraulic signals
- Composite indices: radiation, hydraulic imbalance, thermal stress
- Yeo–Johnson transform + standardization for skewed sensors
- PCA retaining 95% variance; store components as pc_01 … pc_K

Code snippet (rolling stats, slopes):
```python
for w in [5, 15, 60]:
    for col in ["sump_flow_lpm", "airborne_gamma_uSvph", "rcs_mass_balance_lpm", "pressurizer_level_pct"]:
        df_cleaned[f"{col}_rollmean_{w}m"] = df_cleaned[col].rolling(w, min_periods=1).mean()
        df_cleaned[f"{col}_rollstd_{w}m"] = df_cleaned[col].rolling(w, min_periods=1).std().fillna(0)

for col in ["pressurizer_level_pct", "rcs_hot_leg_temp_C", "rcs_cold_leg_temp_C"]:
    df_cleaned[f"{col}_delta_1m"] = df_cleaned[col].diff().fillna(0)
    df_cleaned[f"{col}_slope_5m"] = df_cleaned[f"{col}_delta_1m"].rolling(5, min_periods=1).mean()
```

Code snippet (indices, transforms, PCA):
```python
# Composite indices
rad_cols = ["airborne_gamma_uSvph", "particulate_cpm"]
```

SECTION 9 — Rationale for Technique and Algorithm Choices
Purpose: Anticipate stakeholder questions about “why this approach?” and articulate trade-offs.

Data Generation:
- Chose minute-level cadence and diurnal baselines to mirror operational physics and control cycles; supports temporal feature learning.
- Injected gradual and rapid leaks to test sensitivity to different failure modes; impacts multiple correlated sensors for realism.
- Added false positives (rad/humidity) to evaluate robustness against confounders.
- Introduced MCAR missingness, contiguous outages, and drift to reflect real data quality issues observed in industrial telemetry.

Preprocessing & Data Quality:
- Gap policy (short ffill/bfill; medium interpolation; long flag-only) balances continuity with integrity—avoids fabricating long stretches that could bias models.
- IQR + rolling-MAD outlier detection captures both global and local anomalies; event-aware capping preserves true leak signatures.
- Savitzky–Golay and rolling median chosen for denoising due to edge behavior and trend preservation compared to aggressive filters.
- Simple drift correction via median shift is transparent, low-variance, and adequate for synthetic drift; complex methods (e.g., CUSUM, BOCPD) are future options.

Feature Engineering & Transformations:
- Rolling stats and slopes encode short-term dynamics relevant to leak onset without requiring sequence models.
- Composite indices improve interpretability for non-ML stakeholders by aggregating physics-consistent signals.
- Yeo–Johnson handles zeros/negatives and reduces skew, improving linear model assumptions and SVM/RF stability.
- PCA retains 95% variance to decorrelate features and reduce noise while keeping interpretable raw indices alongside components.

Modeling — Classification:
- Included a spectrum from linear (Logistic Regression) to non-linear (Tree/Forest/SVM/KNN) to benchmark bias–variance trade-offs.
- Decision Tree and Random Forest favored for interpretability (rules/feature importance), non-parametric flexibility, and handling of mixed scales.
- SVM with probability=True provides strong margins; useful when classes are separable after engineering.
- KNN acts as a simple non-parametric baseline sensitive to local structure.
- Stratified splits and cross-validation control variance on class imbalance (leak vs normal).

Modeling — Regression (Leak Rate):
- Random Forest selected as primary due to non-linear response and interaction handling; robust to outliers after policy.
- Linear/Ridge retained as baselines for interpretability and to detect overfitting signals.
- SVR tested for smooth function approximation; useful when kernel captures structure.
- KNN regression offers a locality-based comparator.

Association Rules:
- Binning and one-hot encoding enable market-basket style patterns; rules focused on leak/high-risk to surface actionable co-occurrences.
- Lift/confidence thresholds chosen to avoid spurious patterns on sparse events.

Visualization:
- Heatmaps, pies, boxplots, temporal overlays, PCA scatter/loadings selected to communicate to both technical and executive audiences.
- Model comparison charts and confusion matrices provide quick performance narratives; regression identity plots show calibration.

Limitations & Future Work:
- Synthetic data can overstate performance; next steps include domain calibration, drift-aware retraining, cost-sensitive learning, and temporal models (e.g., HMM/LSTM).
- Expand uncertainty quantification and establish alert thresholds tied to operational risk.
