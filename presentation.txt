The synthetic data generation creates realistic nuclear plant sensor data with known ground truth for leak events. This approach allows for controlled testing of detection algorithms and provides a benchmark for real-world implementation.

```python
def baseline(mean, sd, daily_amp=0.0):

    arr = np.random.normal(loc=mean, scale=sd, size=n)
    if daily_amp:
```

```python
# Gradual leaks: linear ramp over time
if leak_type == "gradual":
```

SECTION 2: DATA PREPROCESSING & QUALITY ASSURANCE
=================================================

PURPOSE & JUSTIFICATION:
Preprocessing ensures data quality while preserving true leak signatures. The approach balances data continuity with integrity, avoiding over-cleaning that could bias models.

KEY TECHNIQUES IMPLEMENTED:

1. Gap Categorization and Handling:
```python
# Short gaps (≤5 min): Forward/backward fill
df_shortfilled[col] = df[col].ffill(limit=5).bfill(limit=5)

# Medium gaps (≤30 min): Time-based interpolation
df_interp[col] = df_shortfilled[col].interpolate(method="time", limit=30)

# Long gaps (>30 min): Flag only, no imputation
def contiguous_nan_segments(series):
    is_na = series.isna().astype(int)
    groups = (is_na != is_na.shift()).cumsum()
    for g, sub in series.groupby(groups):
        if sub.isna().all():
            yield sub.index[0], sub.index[-1], len(sub)

# Flag long outages
for col in sensors:
    for s, e, length in contiguous_nan_segments(df[col]):
        if length >= 31:
            long_mask.loc[s:e] = True
```

2. Outlier Detection with Event-Aware Policy:
```python
# IQR-based outlier detection
def iqr_bounds(series):
    q1, q3 = series.quantile(0.25), series.quantile(0.75)
    iqr = q3 - q1
    return q1 - 1.5*iqr, q3 + 1.5*iqr

# Preserve leak events, cap only non-event outliers
event_mask = df["ground_truth_leak_flag"].fillna(False)
non_event_mask = ~event_mask
cap_mask = non_event_mask & ((df[col] < lower) | (df[col] > upper))
df_cleaned.loc[cap_mask, col] = df_cleaned.loc[cap_mask, col].clip(lower, upper)
```

3. Denoising Techniques:
```python
# Rolling median (preserves edges)
df_cleaned[col + "_rolling_median"] = df_cleaned[col].rolling(5, center=True, min_periods=1).median()

# Savitzky-Golay filter (smooth trends)
sg = savgol_filter(arr, window_length=11, polyorder=2, mode='interp')
df_cleaned[col + "_savgol"] = sg
```

4. Drift Detection and Correction:
```python
def detect_and_correct_drift(series):
    mid = len(series)//2
    first_med, second_med = series.iloc[:mid].median(), series.iloc[mid:].median()
    shift = second_med - first_med
    if abs(shift) > 3 * series.std():  # 3-sigma threshold
        corrected = series.copy()
        corrected.iloc[mid:] = corrected.iloc[mid:] - shift
        return corrected, shift
    return series, 0.0
```

SECTION 3: FEATURE ENGINEERING & TRANSFORMATIONS
================================================

PURPOSE & JUSTIFICATION:
Feature engineering creates interpretable indicators and reduces dimensionality while preserving information. The approach combines domain knowledge with statistical techniques.

KEY TECHNIQUES IMPLEMENTED:

1. Rolling Statistics (Multiple Time Windows):
```python
# Rolling windows: 5, 15, 60 minutes
for w in [5, 15, 60]:
    for col in key_sensors:
        df_cleaned[f"{col}_rollmean_{w}m"] = df_cleaned[col].rolling(w, min_periods=1).mean()
        df_cleaned[f"{col}_rollstd_{w}m"] = df_cleaned[col].rolling(w, min_periods=1).std().fillna(0)
```

2. Temporal Derivatives (Slopes and Rates):
```python
# Minute-to-minute changes and 5-minute rolling slopes
for col in ["pressurizer_level_pct", "rcs_hot_leg_temp_C", "rcs_cold_leg_temp_C"]:
    df_cleaned[f"{col}_delta_1m"] = df_cleaned[col].diff().fillna(0)
    df_cleaned[f"{col}_slope_5m"] = df_cleaned[f"{col}_delta_1m"].rolling(5, min_periods=1).mean()
```

3. Composite Indices (Domain-Specific):
```python
# Radiation Index (weighted combination)
rad_cols = ["airborne_gamma_uSvph", "particulate_cpm"]
rad_std = (df_cleaned[rad_cols] - df_cleaned[rad_cols].median()) / df_cleaned[rad_cols].std()
df_cleaned["radiation_index"] = 0.6*rad_std["airborne_gamma_uSvph"] + 0.4*rad_std["particulate_cpm"]

# Hydraulic Imbalance Index
df_cleaned["hydraulic_imbalance_index"] = (
    (df_cleaned["makeup_flow_lpm"] - df_cleaned["letdown_flow_lpm"]) /
    (df_cleaned["makeup_flow_lpm"] + df_cleaned["letdown_flow_lpm"] + 1e-6)
)

# Thermal Stress Index
df_cleaned["thermal_stress_index"] = df_cleaned["temp_gradient_C"] * (
    df_cleaned["primary_flow_kgps"].mean() / (df_cleaned["primary_flow_kgps"] + 1e-6)
)
```

4. Power Transformations (Yeo-Johnson):
```python
# Handle skewed distributions
pt = PowerTransformer(method="yeo-johnson", standardize=False)
Xt_pt = pt.fit_transform(df_cleaned[transform_cols].fillna(0))

# Standardization after power transform
scaler = StandardScaler()
Xt_scaled = scaler.fit_transform(df_cleaned[[c + "_yeojohnson" for c in transform_cols]])
```

SECTION 6: TECHNICAL RATIONALE & METHODOLOGY
============================================

JUSTIFICATION FOR TECHNIQUE SELECTIONS:

1. Data Generation Choices:
- Minute-level cadence: Mirrors operational control cycles and supports temporal feature learning
- Diurnal patterns: Realistic daily variations in plant operations
- Multi-sensor correlation: Leak events affect multiple systems simultaneously
- False positives: Tests algorithm robustness against confounders
- Missing data simulation: Reflects real-world telemetry quality issues

2. Preprocessing Strategy:
- Gap handling policy: Short gaps (ffill/bfill) preserve continuity, long gaps (flag only) maintain integrity
- Event-aware outlier handling: Preserves true leak signatures while cleaning noise
- Savitzky-Golay denoising: Better edge preservation than aggressive filters
- Simple drift correction: Transparent and adequate for synthetic data

3. Feature Engineering Rationale:
- Rolling statistics: Capture short-term dynamics without sequence models
- Composite indices: Improve interpretability for non-ML stakeholders
- Yeo-Johnson transform: Handles zeros/negatives, reduces skew for linear models
- PCA at 95% variance: Balances dimensionality reduction with information retention

4. Modeling Approach:
- Multiple algorithms: Benchmark bias-variance trade-offs
- Random Forest preference: Non-parametric, handles interactions, provides feature importance
- Stratified splits: Control variance on class imbalance
- Cross-validation: Robust performance estimation
